# vrf-assignment-uniformity

**Claim:** Given a job seed and a set of registered runner pubkeys, VRF-based assignment selects runners uniformly at random (in expectation), is deterministic given `(seed, pubkey)`, is unpredictable to runners prior to seed publication, and is publicly verifiable post-hoc.

**Property:**
- **Determinism:** `vrf_output(sk, seed)` yields the same value across calls.
- **Verifiability:** `vrf_verify(pk, seed, output, proof)` returns `Ok` iff the proof was generated by the matching `sk`.
- **Uniqueness of proof for (sk, seed):** there is at most one verifying proof; malleability test rejects mutated proofs.
- **Empirical uniformity:** over Hegel-drawn seeds and a fixed runner set of size `N`, the empirical selection frequency per runner converges to `1/N` within statistical bound for the sample size (weak pointwise: max deviation ≤ ε for K draws).

**Test shape:** direct `#[hegel::test]` for determinism / verifiability / malleability. Uniformity uses a seed-driven inner loop (prior-memory guidance: CBOR cost is superlinear above N²≈1000 draws, so use `mc::Rng` for the inner sampling).

**Scope:** The *statistical* fairness of assignment under churn is `scheduling-fairness` (B-stat). Collusion resistance is `collusion-probability` (B-stat). This card is the foundational uniformity property both depend on.
