# Code of conduct

CosaCI follows the [Contributor Covenant, version 2.1].
Contributors and reviewers are expected to read it and behave
accordingly when participating in this project — issues, pull
requests, discussions, code review, and any other community
spaces tied to this repository.

[Contributor Covenant, version 2.1]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## Reporting

Conduct concerns go to **`conduct@codetestcode.io`**. Reports are
acknowledged within 3 working days and handled by the project
maintainers. Reporters can request anonymity from the wider
community at the time of reporting; that preference is
respected.

If the report concerns a maintainer, address it to the
remaining maintainers via the same address — they will recuse
the named maintainer from the response.

## Scope

This code applies anywhere this project's name is on the door:

- the `copyleftdev/cosaci` GitHub repository (issues, PRs,
  discussions, releases),
- any official communication channel set up specifically for
  the project,
- any in-person or remote event where someone is representing
  the project (a CosaCI-affiliated talk, table, or workshop).

It does not extend to general behavior in unaffiliated venues,
unrelated repositories, or private conversations between
contributors that don't reach the project's surface.

## Enforcement

Maintainers may apply the enforcement remedies described in
the Contributor Covenant — private warning, public warning,
temporary or permanent ban — proportional to the severity of
the breach. The audit trail this project keeps for code (every
falsifiable claim has a card and a test) does not extend to
private conduct reports; those are handled with appropriate
confidentiality.
